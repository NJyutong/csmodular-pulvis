# Pulvis 0.0.6

## English

### Complete Backend DSP Upgrade, Musical Workflow & Install Integrity

- **Complete Backend DSP Algorithm Upgrade:** Rebuilt the shared Csound granular engine (`csound/GrainCore.txt`) from the ground up with a unified 128-slot branchless voice pool (`0..63` persistent active voices + `64..127` block-local expiring snapshots), precomputed 4097-point Hann/Blackman window LUTs (eliminating per-sample `cos()` calls in the hot loop), instantaneous envelope-weight overlap normalization (coherent grains can grow louder as density rises), piecewise $C^1$ zero-THD soft-knee feedback saturation, and 3-tier **Auto CPU Mode** (`Eco` / `Balanced` / `Studio HQ`, up to `3.88×` faster in Eco on extreme `+48 st` workloads).
- **Unified Target-Note Quantizer (Pitch Quantization):** Supports both **Relative interval** (Octaves, Octaves + 5ths, Major/Minor Pentatonic — default-safe for live FX, drums, chords, and legacy patches) and **Lock to key** (Key root `C`–`B` + Major, Natural Minor, Pentatonic, Dorian). Grain Osc quantizes knob + CV + jitter directly from its known `A3` root with phase-coherent carrier alignment; Grain Sample supports per-slot **Sample root + fine detune (`±50 c`)**; Grain Freeze stays honestly in Relative interval mode.
- **Host BPM Tempo Sync & Project Persistence:** Connects directly to CsModular's `bpm` channel (`1/1` through `1/32`, including triplets) with phase-preserving tempo changes and full `TimeJitter` humanization. Module engine options (pitch quantization, tempo sync, Wet Tone, per-slot WAV roots/cents) now persist in patch JSON (`pulvisSettings`), resync automatically across recompiles, and share across polyphonic host voices.
- **Grain Freeze Wet Tone:** Constant-loudness wet-only spectral tilt placed strictly after the feedback tap and before the Dry/Wet mix, letting the frozen cloud warm or brighten without dulling dry audio or compounding in feedback.
- **Grain Sample `Scan` CV Jack & Streamlined Grain Osc:** Added an independent CV modulation jack (`id: 118`) beside Grain Sample's `Scan %/s` knob, and removed redundant forward/reverse direction controls from Grain Osc (now a clean 14-parameter / 12-CV layout).
- **Studio Panel Ergonomics:** Reordered Grain Freeze Row 1 (`Freeze → Capture → Source`) with emerald snapshot confirmation, expanded knob hitboxes across numeric readouts, magnetic zero/center detents (`Level`, `Scan`, `Pan`), `Alt + click` inline exact numeric input, MIDI Learn indicators, and refined `Audio in` label/jack layout.
- **Install-Time Integrity Verification:** Added `_manifest.sha256.json` covering all modules, shared core, metadata, demo patch, and host integration patches. The source installer (`scripts/install.mjs`) and desktop installer scripts verify every SHA-256 digest before touching the host and abort immediately if any file is missing or tampered with.

## 简体中文

### 后端算法全面升级、音乐性工作流与安装校验

- **后端算法全面升级：** 全面重构共享 Csound 颗粒合成核心（`csound/GrainCore.txt`），引入统一 128 槽位无分支声部池（`0..63` 常驻声部 + `64..127` 块内到期快照）、预计算 4097 点 Hann/Blackman 窗查表（消除热循环每秒数百万次 `cos()` 运算）、瞬时包络权重归一化（同相颗粒的响度仍随密度上升）、分段 $C^1$ 零谐波软膝反馈限幅，以及默认按设备硬件自动选档的三档 **性能模式**（`Eco` / `Balanced` / `Studio HQ`，极限 `+48 st` 场景下 Eco 模式提速最高 **`3.88×`**）。
- **统一目标音量化器（音高量化）：** 提供 **相对音程**（八度、八度+纯五度、大/小调五声，安全适配实时音频、鼓、和弦与旧工程）与 **锁定到调**（主音 `C`–`B` + 自然大调、自然小调、大/小五声、多利亚）。`GrainOsc` 基于内置 `A3` 基准音高将旋钮、CV 与抖动统一吸附至目标调内并同步校准载波相位；`GrainSample` 支持按采样槽设置 **采样原音 + 微调（`±50 c`）**；`GrainFreeze` 保持诚实的相对音程模式。
- **宿主 BPM 节拍同步与工程持久化：** 直连宿主 `bpm` 通道（支持 `1/1` 至 `1/32` 含三连音），变速时保持剩余节拍相位与 `TimeJitter` 偏移不跳拍。模块的音高量化、节拍同步、湿声音色及各槽采样原音微调现均持久化保存于工程 JSON（`pulvisSettings`），重编译自动回写并在复音宿主各声部间同步共享。
- **颗粒冻结独有「湿声音色 / Wet Tone」：** 等响度频谱倾斜滤波严格置于反馈抽头之后、干湿混合之前，让冻结颗粒云独立变暖或提亮，干声清晰不闷且绝不回灌叠加。
- **采样扫描 CV 与振荡器精简：** 为 `GrainSample` 的 `扫描 %/秒` 新增独立 CV 调制插孔（`id: 118`）；移除 `GrainOsc` 上对周期波冗余的播放方向控件，精简为对称的 14 参 / 12 CV 排布。
- **面板人体工学打磨：** `GrainFreeze` 第一行按 `冻结 → 快照 → 播放来源` 一字排开并配薄荷绿捕捉回执；旋钮热区融合右侧数值框；`Level` / `Scan` / `Pan` 增加磁吸零位/中点；支持 `Alt + 点击` 原地键盘精确输入、MIDI Learn 指示点，并优化了 `音频输入` 标签与插孔排布。
- **安装时文件完整性校验：** 新增 `_manifest.sha256.json` 清单，覆盖所有模块、共享核心、元数据、示例工程与宿主集成补丁。命令行安装器（`scripts/install.mjs`）及桌面安装脚本在写入宿主前均会逐一校验 SHA-256，若文件缺失或被篡改将立即中止安装。

## Русский

### Полное обновление алгоритмов DSP, рабочего процесса и проверка целостности

- **Полное обновление бэкенд-движка DSP:** общее гранулярное ядро Csound (`csound/GrainCore.txt`) полностью переработано — единый 128-слотовый пул голосов без ветвлений (`0..63` активные голоса + `64..127` локальные снимки блока), предвычисленные таблицы окон Ханна и Блэкмана (4097 точек, без вызова `cos()` в горячем цикле), мгновенная нормализация по весу огибающей (при синфазном сложении громкость растёт с плотностью), кусочно-гладкий $C^1$ мягкий ограничитель обратной связи и 3-уровневый **Режим CPU** (**Авто** по характеристикам устройства, либо ручной выбор Баланс / Эко / Студия HQ — до `3,88×` быстрее в режиме Эко).
- **Единый квантизатор целевой ноты:** поддерживает режимы **Относительный интервал** (октавы, октавы + квинта, пентатоника) и **В тональность** (тоника `C`–`B` и лад). Grain Osc квантизирует высоту от встроенной опоры `A3` с фазовой синхронизацией несущей; Grain Sample поддерживает настройку **Основного тона слота и подстройки (`±50 c`)**; Grain Freeze честно использует относительные интервалы.
- **Синхронизация BPM и сохранение в проекте:** прямое подключение к каналу `bpm` хоста (`1/1`–`1/32`, включая триоли) с сохранением фазы при смене темпа и разброса `TimeJitter`. Настройки движка (квантизация, синхронизация, Wet Tone, тоника и подстройка каждого слота WAV) сохраняются в JSON проекта (`pulvisSettings`), автоматически синхронизируются после перекомпиляции и разделяются между полифоническими голосами.
- **Тон влажного сигнала (Wet Tone) в Grain Freeze:** равногромкий наклонный фильтр расположен строго после отвода обратной связи и до микса Dry/Wet, позволяя утеплять или осветлять гранулярное облако без потери чёткости сухого сигнала.
- **CV-вход для Scan и оптимизация Grain Osc:** добавлен отдельный CV-вход модуляции скорости сканирования (`id: 118`) в Grain Sample; убран избыточный переключатель направления в Grain Osc (чистая схема 14 параметров / 12 CV).
- **Эргономика панелей:** рабочий ряд `Заморозка → Снимок → Источник` в Grain Freeze с подтверждением сохранения, объединённая зона клика ручки и цифрового поля, магнитная фиксация нуля/центра (`Level`, `Scan`, `Pan`), `Alt + клик` для точного ввода с клавиатуры и улучшенное расположение подписи и гнезда `Аудиовход`.
- **Проверка целостности при установке:** добавлен манифест `_manifest.sha256.json` для всех модулей, общего ядра, метаданных, демо-патча и патчей интеграции. Установщики проверяют контрольные суммы SHA-256 до внесения изменений в хост и прерывают установку при повреждении или подмене любого файла.
