# Pulvis 0.0.5

## English

Pulvis adds three Csound granular synthesis modules for CsModular: Grain Freeze, Grain Sample and Grain Osc. The shared grain engine runs in Csound and routes audio through the host's Zak buses. The package includes the CLI integration installer, matte graphite widescreen (`500 × 300`) hardware panels with live Csound oscilloscope and 2048-point FFT display, HiDPI canvas alignment, three-language panel/menu switching (keeping the host module browser in English), panel color tinting with `Follow theme` reset, localized manuals, separate native Windows x64 and Windows ARM64 installers, separate native macOS Apple Silicon (`arm64`) and Intel (`x64`) `.pkg` installers, a standard native Linux amd64 Debian `.deb` package (no WebView/GTK/WebKit dependencies), and a source archive. No demo WAV is bundled; empty Grain Sample slots provide a direct **Open WAV…** button.

All desktop installers target CsModular 0.1.5 with the Pulvis host integration and require no WebView runtime. SHA-256 files are included with each package.

## Русский

Pulvis 0.0.5 добавляет в CsModular три модуля гранулярного синтеза на Csound: Grain Freeze, Grain Sample и Grain Osc. Общий движок работает в Csound, а звук проходит через шины Zak хоста. В выпуск входят сценарий интеграции для исходного кода, матовые графитовые широкоформатные панели (`500 × 300`) с живой осциллограммой и БПФ-спектром (2048 точек) из Csound, HiDPI-выравнивание холста, переключение трёх языков на панелях и в контекстных меню модулей (при сохранении английского браузера модулей хоста), окраска панели с возвратом к теме, руководства на трёх языках, отдельные нативные установщики для Windows x64 и Windows ARM64, отдельные нативные пакеты `.pkg` для macOS Apple Silicon (`arm64`) и Intel (`x64`), стандартный пакет Debian `.deb` для Linux amd64 (без зависимостей WebView/GTK/WebKit) и архив исходников. ## Changes in the current build

The changes below are in the updated CsModular host and Pulvis panels. The published 0.0.5 desktop installers predate this menu update.

- **Live displays.** Grain Osc shows its carrier and output waveform. Grain Freeze shows its recording or captured snapshot. Grain Sample shows the WAV in the selected slot. Moving dots follow active grains, and the window curve shows their progress during playback.
- **Spectrum on demand.** Right-click a module title and choose **Show left-channel spectrum**. Choose **Show source** to return. Each module has its own view, and the title bar stays clear.
- **Correct stereo routing.** Unplug both cables to Outs2 and the speakers fall silent while the module display continues to run. Connect just the left or right input to hear only that channel.
- **Panel controls.** Choose one of eight WAV slots on the display and open a local file from an empty slot. Double-click a knob to restore its default or hold Shift while dragging for finer adjustment. The right-click menu also has language selection and a centered **About** dialog with the website and MIT license.

### 简体中文

以下功能已在配套新版 CsModular 宿主和 Pulvis 面板中实现。下方提供的 0.0.5 桌面安装包早于这次菜单更新。

- **播放时能看到实际音源。** 颗粒振荡器显示载波与输出波形，颗粒冻结显示录音或已捕捉的快照，颗粒采样显示所选槽位的 WAV。移动的光点对应正在播放的颗粒，右侧包络曲线显示它们的播放进度。
- **按需查看频谱。** 右键模块标题，选择 **显示左声道频谱**，再选 **显示音源** 即可切回。三个模块可以分别切换，标题栏右上角留空。
- **修复断线后仍然出声的问题。** 拔掉通往 Outs2 的两根线，扬声器静音，面板仍可观察信号。只接左路或右路时，只有对应声道出声。
- **面板操作。** 选一个空槽，再点击 **导入 WAV…** 选择本地文件。双击旋钮恢复默认值，按住 Shift 拖动可以微调。右键菜单还可以切换语言，或打开居中的 **关于** 窗口查看项目网址和 MIT 许可证。

### Русский

Эти изменения доступны в обновлённых панелях Pulvis и совместимой версии CsModular. Опубликованные установщики 0.0.5 вышли до обновления меню.

- **Вид источника.** Grain Osc показывает несущую и выходной сигнал, Grain Freeze — запись или сохранённый снимок, а Grain Sample — WAV выбранного слота. Точки отмечают активные гранулы и их положение на огибающей во время воспроизведения.
- **Переключение спектра.** Щёлкните правой кнопкой по заголовку и выберите **Показать спектр левого канала**. Команда **Показать источник** вернёт прежний вид. Настройка действует на один модуль, правый угол заголовка остаётся свободным.
- **Исправлена маршрутизация стереозвука.** Если отсоединить оба кабеля от Outs2, колонки замолчат, а дисплей продолжит показывать сигнал. При подключении только одного входа звучит соответствующий канал.
- **Управление.** Выберите пустой слот и откройте свой WAV. Двойной щелчок возвращает ручку к исходному значению, а Shift при перетаскивании позволяет точнее его настроить. В контекстном меню можно выбрать язык или открыть окно **О модуле** с сайтом проекта и лицензией MIT.
